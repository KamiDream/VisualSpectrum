# VisualSpectrum —— pip 运行期依赖（跨平台；Windows 打包用这份）
#
#   python -m pip install -r requirements.txt

PyQt6>=6.11                 # 窗口 + 托盘 + 单实例
PyQt6-WebEngine>=6.11       # 浮层渲染（Canvas）—— 必装，整套视觉靠它
Flask>=3.1                  # 配置页与 REST 接口
numpy>=1.26                 # FFT（把音频变成频谱）
soundcard>=0.4.3            # 系统回环捕获：Windows(WASAPI) / Linux(PulseAudio·PipeWire)

# ⚠ 关于音频依赖：
#   * `soundcard` 负责"抓到系统正在播放的声音"（回环）。它抓不到时程序会自动退回到
#     **demo 合成频谱**（画面照样是活的），所以它是"好用"而不是"必需"。
#   * numpy 是 FFT 的必需项；没有它就只能跑 demo 模式。
#   * 若 `soundcard` 在你的机器上不灵，可改用 `sounddevice`（Windows 的 WASAPI loopback
#     走它也行）：`pip install sounddevice`——程序会按 soundcard → sounddevice 的顺序尝试。
